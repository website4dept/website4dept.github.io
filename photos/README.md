# Photos for people pages

Put one photo per person in this folder, named with the person's id from people-data.js:

    photos/adrijit-goswami.jpg
    photos/ratna-dutta.jpg

- Square or portrait (4:5) photos work best, about 600 × 600 px, under 200 KB.
- To change a photo, upload a new file with the same name. It changes on the directory card and the profile page.
- No photo yet? The initials are shown automatically.
